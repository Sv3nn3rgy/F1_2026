🔄 UPDATING WITH NEW RACES
================================================================================

Have new race data?

1. Update your CSV files with predictions and results
2. Run: python race_scoring.py
3. Run: python generate_dashboard_data.py
4. Refresh dashboard.html in browser
5. New data appears automatically!

💾 KEEPING YOUR CUSTOM COLORS

⚠️ COMMON ISSUES
================================================================================

"Page won't load"
→ Make sure dashboard.html and dashboard_data.json are together

"Charts are blank"
→ Open browser console (F12) and check for errors
→ Try refreshing the page

"Colors aren't saving"
→ Disable private/incognito browsing mode
→ Check that cookies are enabled

"Data is old"
→ Run: python generate_dashboard_data.py
→ Refresh browser (Ctrl+R)
