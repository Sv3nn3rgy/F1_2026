📈 UNDERSTANDING THE VISUALIZATIONS
================================================================================

LEADERBOARD:
- Rank column: Player's current position
- Player column: Name with color dot for quick identification
- Total column: Cumulative points across all races (bolded, in player color)
- Last Race column: Points earned in most recent race event
  → Good for identifying who's "hot" right now

BAR CHART:
- X-axis: Each race/sprint event
- Y-axis: Points (0-15 typical range)
- Bars: One per player per race, colored by player theme
- Patterns: Shows which players excel at which types of events
  → Useful for identifying strengths (some may prefer Sprints vs Races)

LINE CHART:
- X-axis: Events in chronological order
- Y-axis: Total cumulative points (only increases, never decreases)
- Lines: One per player, colored by their theme
- Slope: Shows scoring rate (steep = gaining points fast, flat = not scoring)
- Semi-transparent fill below lines: Creates visual weight and hierarchy
  → Best for seeing overall championship progression and leader trends
